# Portland Response Center (UI Sandbox)
Built: 2025-08-19T20:21:28.455746Z

Single-page app with panel switching (Dashboard / Map / Police).
- Live NWS banner (api.weather.gov)
- Dashboard metrics (Road Closures, Open Shelters)
- Map with Shelters, Road Closures, Equipment, Weather Alerts
- Smart queries: buffer by address, equipment thresholds

Deploy: push to GitHub Pages (root) or run via `python -m http.server` locally.
